Quick Start Guide 1. Set Grade Weights: Define the percentage contribution for each component (must total 100%) and click Save Weights. 2. Add Your Classes: Enter a class name and target score, then click "+" to add it. 3. Select a Class: Choose your active class from the dropdown menu to manage its grades. 4. Enter Scores: Input your midterm and finals scores, then add individual assignment scores using "+". Tip: Check "Is already an Average Score" if you have a single composite assignment grade rather than individual task scores. 5. Calculate: Click Calculate / Save Scores to view your projected outcome against your goal.
